# PDF Question Answering System using RAG

## About the Project

This project is a PDF Question Answering System using Retrieval-Augmented Generation (RAG). It retrieves relevant information from a PDF document and uses a Large Language Model (LLM) to generate answers to user questions.

## How It Works

PDF Document → Text Extraction → Text Chunking → Embeddings → FAISS Similarity Search → LLM → Answer

## Technologies Used

* Python
* PyPDF2
* OpenAI Embeddings
* FAISS
* NumPy
* GPT-4o-mini
* Jupyter Notebook

## Project Files

* `New RAG.ipynb` — Jupyter Notebook containing the RAG implementation.

## Key Learning Outcomes

* PDF text extraction
* Text chunking and preprocessing
* Text embeddings
* Similarity search using FAISS
* Question answering using an LLM
* Understanding the Retrieval-Augmented Generation (RAG) pipeline
